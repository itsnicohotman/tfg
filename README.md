  This repository holds the development of my Engineering in Industrial Technologies BSc.'s Thesis.

The goal of this thesis is to develop a model of a dual arm manipulator hanging from a quadrotor UAV with variable rigid cables. Once developed the model, it is to be simulated and controlled in mujoco (https://mujoco.readthedocs.io/en/stable/overview.html).
